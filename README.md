# proteomic_MLGo
Small project where I analyze a public proteomics dataset using Python, fitting a machine learning algorithm on it and extracting Go-Terms for GO-Terms Enrichment Analysis. Finally I identified certain biological functions of interest for determining the tissue of origin of certain cancer cell lines.
